# Velmira أنمي — تطبيق iOS

تطبيق SwiftUI عربي يتصل بـ Worker الخاص بك (velmira-anime-v2-api):
قائمة الأنمي بالصور، بحث، ترتيب حسب السنة، الحلقات، تسجيل دخول، ومشغل فيديو كامل (يدعم PiP وAirPlay).

## البناء بدون ماك (GitHub Actions)
1. أنشئ مستودع جديد على GitHub (مثلاً VelmiraAnime-iOS).
2. ارفع كل محتويات هذا المجلد (ومعها مجلد `.github`).
3. من تبويب Actions شغّل "Build IPA (unsigned)" (أو يشتغل تلقائياً عند الرفع).
4. بعد ما يخلص، نزّل `VelmiraAnime-IPA` من أسفل صفحة التشغيل.

## التثبيت
الـ IPA غير موقّع: ثبّته عبر TrollStore أو Sideloadly أو AltStore/SideStore أو eSign.

## الإعدادات داخل التطبيق
زر الحساب (أعلى الشاشة): تسجيل الدخول، الجودة، ورابط الـ Worker.
